# 追加の条件 4: 停滞の時間を含まない打鍵の速さで固定し直す（計算の前にコミットする）

- 日付: 2026-11-07。これまでの条件（08010482・6df7bde6・b5687936・9a1b321c）への追加。どれも変えない。
- 理由: 外枠の attack-me round 3（[internal reference removed]）で、追加の条件 3 の押下の率（観測区間の時間あたりの押下）は停滞の時間を分母に含むので、固定すると停滞そのもの（部分と全体）を引いている恐れがある、と全役が指摘した。研究者が、停滞の時間を含まない打鍵の速さで固定し直すと決めた（[internal reference removed]）。
- 見たもの: 追加の条件 3 の結果（`round2_press.json`）の全部と、その族・止まりの条件ごとの内訳（verdict の C）。打鍵の速さと停滞の率・得点の関係は見ていない（速さは書き手の間の分布の中央値と四分位だけ見た）。

## 量

- 書き手の打鍵の速さ: KLiCKe の各書き手で、観測区間の中の隣り合う押下の間隔のうち 2 秒未満のものの中央値（ms）。2 秒は作文の休止の慣行の閾値。停滞を始める長い間隔（固定 θ は 10 秒以上）はほぼ入らない。ただし本人の分位の θ が 2 秒未満の書き手では θ を超える間隔の一部が入りうること、停滞の区間の中の削除の押下の短い間隔は入ることを限界に書く（`round2_press.py` の速さの記述と同じ量）。値が小さいほど速い。
- 各通りで:
  - S1 書き手の停滞の率と打鍵の速さの Spearman。
  - S2 得点と停滞の率の、打鍵の速さを固定した偏順位相関と区間（書き手を単位にした再標本 2,000 回・SEED）。
- 参照: 得点と打鍵の速さの Spearman（区間つき）。
- 記述の値も JSON に名前つきで残す（R3 m-2）: 89 通りの間で、元の相関と S1・P1（押下の率との相関）の相関（Pearson・全体と族ごと）、S2 と P2（押下の率で固定）を止まりの条件ごとに数えた正・負・0 を含む数。

## 読み方（先に置く）

- 打鍵の速さで固定した S2 が、どの通りでも |S2| ≤ 0.1 なら「停滞の時間を含まない速さで固定しても、関連は小さい」と書く。
- S2 の範囲が押下の率で固定した P2 の範囲（−0.054〜+0.106）より明らかに広い（どちらかの端が 0.05 以上外へ）なら「押下の率で固定して小さくなった分の一部は、停滞の時間を分母に共有したことによる」と書く。
- S2 で区間が正・負になる通りの、止まりの条件ごとの数を報告する。止まりの条件で符号が分かれる構造（P2 で文字だけ 45/45 が正）が S2 でも残るかを書く。
- [internal reference removed] との対比は、S2 の基準の値と範囲で書く（[internal reference removed] は速さを調整しても負が残った）。

## 確かめ

- selftest は `round2_press.py` と同じ偏相関の関数を使う（緑を確かめる）。
- 出すのは集計値だけ。書き手ごとの値・ID・本文は出さない。
